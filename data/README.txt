Place your two original CSV datasets in this folder:

1. Phishing URLs.csv  (must contain a column named: url)
2. URL dataset.csv    (must contain a column named: url)

The training script assigns label 1 to the first file (phishing) and label 0
 to the second file (legitimate). Verify the source labels before training.
The datasets were not included because they were not attached with the code.
